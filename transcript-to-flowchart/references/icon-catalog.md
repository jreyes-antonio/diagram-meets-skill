# Icon catalog

Choose by meaning, not by visual preference.

| Key | Use |
|---|---|
| `start` | Start or trigger |
| `end` | Final outcome |
| `process` | Generic activity |
| `transform` | Cleaning, mapping, enrichment, ETL |
| `decision` | Conditional branch or approval |
| `database` | SQL database, warehouse, persistent table |
| `excel` | Excel workbook or spreadsheet |
| `file` | CSV, JSON, document, object file |
| `api` | API, webhook, service call |
| `cloud` | Cloud platform or unspecified managed service |
| `queue` | Queue, topic, event bus, streaming channel |
| `person` | User, role, team, manual activity |
| `report` | Dashboard, report, analytics output |
| `email` | Email notification or inbound message |
| `question` | Unknown source, rule, owner, transformation, or destination that requires business clarification |
| `generic` | Unknown or deliberately vendor-neutral system |

When a required concept is absent, add a simple inline SVG symbol to the `ICONS` dictionary in `scripts/render_diagram.py`, update this table, and keep the icon vendor-neutral unless the transcript explicitly names a product.
